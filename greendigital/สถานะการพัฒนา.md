# Green Digital — ฉบับพร้อมฝึกซ้อม 1.0

ระบบหลักครบ: สมาชิก/บทบาท/ระงับบัญชี, กู้รหัสผ่าน, โปรไฟล์, CRUD ประเภทและองค์กร, เนื้อหาตามเวลา, ส่งขยะพร้อมภาพ, ตรวจรับ, รายงานและกราฟ, CSV, แจ้งปัญหาและคำตอบ, เป้าหมายและคะแนน

ใช้ PHP MVC + jQuery 3 + Bootstrap 5 พร้อมไลบรารีออฟไลน์ ฐานข้อมูล MySQL/MariaDB และข้อมูลสมมติพร้อมติดตั้งใหม่ มี SQLite เป็นทางเลือกทดลอง

เริ่มจาก README.md แล้วอ่าน docs/คู่มือฝึก-jquery.md, docs/ฐานข้อมูล.md, docs/เกณฑ์และการสาธิต.md และ docs/ผลทดสอบ.md

ผ่านการทดสอบ API กับฐานข้อมูลและตรวจหน้าจอจริงแล้ว รายละเอียดขอบเขตและสภาพแวดล้อมอยู่ในผลทดสอบ ไม่ใช่ patch สำหรับฐานข้อมูลรุ่นก่อนหน้า

# กรอกข้อมูลเริ่มต้นผ่านฟอร์ม (รุ่น 1.1)

ข้อความยาวใน password ของ demo.sql คือ **hash ที่ PHP สร้าง** นักเรียนไม่ต้องจำ hash และไม่ควรเปลี่ยนเป็นรหัสผ่านธรรมดาในฐานข้อมูล เพราะระบบเข้าสู่ระบบใช้ password_verify()

## ติดตั้งแบบใหม่ใน XAMPP

1. แตกโฟลเดอร์ greendigital ไว้ใน htdocs แล้วเปิด Apache/MySQL
2. Import **sql/greendigital.sql เท่านั้น** และตรวจ Config.php ตาม README
3. ยังไม่ต้อง Import demo.sql หรือรัน setup.php
4. เปิด `http://localhost/greendigital/public/seed.php` บนเครื่องที่ติดตั้งระบบ
5. กรอก/แก้ชื่อและอีเมล 3 บัญชี รหัสผ่าน รหัสกู้คืน บทความ รายการขยะ และเป้าหมาย แล้วกด “บันทึกข้อมูลเริ่มต้นทั้งหมด”
6. กด “ไปหน้าเข้าสู่ระบบ” แล้วใช้อีเมลกับรหัสผ่านที่กรอก

ฟอร์มใส่ค่าเริ่มต้นให้เหมือน demo.sql แก้ได้ก่อนบันทึก รหัสผ่านเริ่มต้น Green1234! สามารถเปลี่ยนเป็นค่าที่จำได้ เช่น Green1234 (อย่างน้อย 8 ตัว) ไม่ต้องจำ hash

รายการขยะทั้งหมดจะเป็นของบัญชีสมาชิก รายการตรวจรับใช้บัญชีเจ้าหน้าที่เป็นผู้ตรวจรับ ราคาอ่านจากประเภทขยะจริงในฐานข้อมูล เว้นน้ำหนักว่างเพื่อข้ามแถวได้ เป้าหมายเป็นเดือนปัจจุบันตามเวลาไทย

## ส่วนที่ต้องจำสำหรับการสร้าง hash

```php
$password = $_POST['password'];
$hash = password_hash($password, PASSWORD_DEFAULT);
```

เมื่อบันทึกผ่าน PDO ให้ส่ง `$hash` ลงคอลัมน์ password ไม่ใช่ `$password` รหัสกู้คืนใช้วิธีเดียวกัน

สูตรหลักของฟอร์มนี้คือ **รับค่า → ตรวจ → hash → บันทึก** ตัวอย่างย่อของการเพิ่มบัญชีหนึ่งคนด้วย Store ของระบบ (ส่วนตรวจสิทธิ์/CSRF/ข้อมูลอยู่ใน seed.php ก่อนส่วนนี้แล้ว):

```php
Store::save('users', [
    'full_name' => $name,
    'email' => $email,
    'role' => 'admin',
    'password' => password_hash($password, PASSWORD_DEFAULT),
    'recovery_hash' => password_hash($recovery, PASSWORD_DEFAULT),
    'created_at' => date('Y-m-d H:i:s')
]);
```

ชื่อฟิลด์ฟอร์มต้องตรงกับ `$_POST` เช่น `<input name="password">` ส่งมาเป็น `$_POST['password']`

ไม่ต้องพิมพ์ INSERT พร้อม hash ยาว ๆ ด้วยตนเอง ชื่อ อีเมล บทความ น้ำหนัก วันที่ และเป้าหมายกรอกผ่านฟอร์มได้ทั้งหมด ส่วนองค์กร/ประเภทขยะมีข้อมูลตั้งต้นจาก greendigital.sql และแก้เพิ่มผ่านเมนูระบบได้หลังเข้าสู่ระบบ

## ข้อกำหนดการใช้งาน

- เปิด seed.php จาก localhost บนเครื่องติดตั้ง เพื่อไม่ให้ผู้อื่นในเครือข่ายสร้างบัญชีผู้ดูแลครั้งแรกแทน
- เมื่อมีผู้ใช้แม้เพียงหนึ่งบัญชี หน้านี้จะปิดการเพิ่มข้อมูลและไม่เปลี่ยนข้อมูลเดิม หาก Import demo.sql ไปแล้ว ให้ใช้เมนูจัดการในระบบตามปกติ
- การบันทึกอยู่ใน transaction ถ้าข้อมูลผิดหรืออีเมลซ้ำ จะยกเลิกทั้งชุด ป้องกันเหลือข้อมูลบางส่วน
- หากจะฝึกใหม่ ให้ใช้ฐานข้อมูลฝึกชื่อใหม่ โดยแก้ชื่อฐานข้อมูลใน SQL และ Config.php ให้ตรงกัน ไม่ลบฐานข้อมูลที่มีข้อมูลจริง
- รหัสร่วมในฟอร์มเป็นข้อมูลฝึก หลังติดตั้งให้แต่ละบัญชีเปลี่ยนรหัสผ่านและรหัสกู้คืนของตนเอง
- demo.sql และ setup.php ยังคงเป็นทางเลือกเดิม แต่ใช้เพียงวิธีเดียวต่อฐานข้อมูลใหม่

## ผลทดสอบส่วนที่เพิ่ม

ทดสอบ HTTP กับฐานข้อมูล SQLite ใหม่: CSRF ผิด รหัสผ่านสั้น อีเมลซ้ำและ rollback บันทึกสำเร็จ การกดซ้ำ บทบาทครบ 3 บัญชี การเข้าสู่ระบบด้วยรหัสที่กรอก บทความตามฟอร์ม และยอดตรวจรับ 43.7 กก./340 บาท ผ่านทั้งหมด 10 จุด ตรวจเพิ่มว่า password/recovery เก็บเป็น hash ที่ตรวจด้วย password_verify ได้ และเป้าหมายถูกบันทึกตามฟอร์ม

ส่วนเพิ่มรุ่นนี้ยังไม่ได้ทดสอบซ้ำบน MariaDB หรือ Windows XAMPP ผลทดสอบเดิมของระบบหลักอยู่ในผลทดสอบ.md
